About pySBC2 Steel Battalion Controller, GameVoice and Nostromo N52 LED feedback, hold confirmation, profiles and key macros
Using the controller Main shows LED brightness. Underlines show held buttons and active switches. Settings → Button setup sets an LED mode, action and optional hold duration. Hold Tank Detach until the confirmation flashes. Release early to cancel. Use Macro editor to create an action, then assign it in Button setup. Auxiliary controls configures the GameVoice and Nostromo N52 switches and keys. Diagnostics shows live input. Themes & profiles changes the active configuration.
